# Prompt Engineering Task 2 – AI UGC Ad Content Generator

## Future Interns – Prompt Engineering Internship

### Task

AI Content Marketing using UGC Ads

## Objective

Build a structured prompt system that generates authentic,
conversion-focused UGC-style advertising content for a real
local business.

The system generates:

- Multiple advertising hooks
- Short UGC-style ad scripts
- Platform-specific content
- Conversion-focused CTAs
- Adaptable brand messaging

## Business

**Business Name:** Salon Nayana

**Business Type:** Hair & Beauty Salon

**Location:** Brigade Road, Bengaluru, Karnataka

## Problem

Local businesses need short-form advertising content that
captures attention quickly while communicating their services
in a natural and relatable way.

Traditional promotional copy can sound overly polished or
sales-focused.

This project uses prompt engineering to create UGC-style
content that feels conversational, authentic, and suitable
for short-form social media advertising.

## Tools Used

- ChatGPT
- GitHub
- Markdown

## UGC Content Pack

The project includes:

- Multiple hooks
- Instagram Reels scripts
- Instagram ad scripts
- YouTube Shorts scripts
- Call-to-action variations
- Platform-specific adaptations

## Prompt Engineering Approach

The prompts are designed using:

1. Role definition
2. Business context
3. Target audience
4. Customer problem
5. Hook generation
6. UGC storytelling
7. Problem → Solution → CTA framework
8. Platform adaptation
9. Authentic conversational tone
10. Output formatting requirements

## Key Features

- Authentic UGC tone
- Multiple hooks for the same business
- Clear conversion intent
- Platform-specific content
- Reusable prompt structure
- Short-form video optimization
